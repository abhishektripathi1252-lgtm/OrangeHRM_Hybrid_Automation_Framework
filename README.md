# OrangeHRM Hybrid Automation Framework

## Project Overview

This is a Hybrid Test Automation Framework developed using Selenium WebDriver, Java, TestNG, Maven, and Jenkins.

The framework follows the Page Object Model (POM) design pattern and supports reusable utilities, reporting, configuration management, and automated regression execution.

---

## Technology Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Jenkins
- Apache POI
- Extent Reports
- Log4j2
- WebDriverManager

---

## Framework Features

- Page Object Model (POM)
- TestNG Framework
- Maven Build Management
- Data Driven Testing
- Excel Utility
- Config Reader
- Wait Utility
- Screenshot Utility
- Test Listener
- Extent Reports
- Parallel Execution
- Jenkins Integration
